# Fajk Studio

An experimental image and video codec with its own desktop encoder and player.

## Key features

- Set a target size and choose between speed and quality.
- Use CPU or GPU processing.
- Encode video with optional inter-frame compression; a decoder SDK and CLI are included.

## Get started

Download the ZIP from Releases and run `Spustit Fajk Studio.cmd`. Files require a compatible decoder.
